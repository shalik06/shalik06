# 🏥 Featured Project — Hospital Management System

## 🏥 MediCore — Hospital Management System

**A full-stack Hospital Management System designed to simplify hospital operations and improve patient management.**

### 🎯 Project Objective

To develop a centralized application for managing patients, appointments, billing, and electronic medical records.

### 🚀 Key Features

- 👤 Patient Management
- 📅 Appointment Scheduling
- 💳 Billing Management
- 📋 Electronic Medical Records
- 🔐 User Authentication
- 📊 Administrative Dashboard
- 💊 Medicine Tracking (Planned)
- ⏰ Medication Reminders (Planned)

### ⚙️ Technology Stack

| Layer | Technology |
|------|------------|
| Frontend | React.js |
| Backend | Java, Spring Boot |
| Database | MySQL |
| ORM | Hibernate / Spring Data JPA |
| Build Tool | Maven |
| Version Control | Git & GitHub |
